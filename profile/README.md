## 👋 About us

**HowTo Software** builds full-stack products: commercial websites, game hosting storefronts and control panels, inventory systems, and publishing platforms. Most of it runs on **ASP.NET Core, Blazor, and SQL Server**, deployed with **Docker**.

🌎 We support **English** and **Brazilian Portuguese (PT-BR)**.
